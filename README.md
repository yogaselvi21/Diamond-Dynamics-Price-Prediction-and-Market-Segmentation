# Diamond-Dynamics-Price-Prediction-and-Market-Segmentation

💎 Diamond Dynamics: Price Prediction and Market Segmentation

📌 Project Overview:

This project uses Machine Learning to predict diamond prices and segment market groups based on quality attributes. The goal is to assist in pricing strategy, inventory management, and customer targeting by providing automated, reliable diamond valuation and classification.

🗂️ Project Structure

Mini_project_4_Data_Cleaning.ipynb: Initial data inspection and handling missing values.

Mini_Project_4_Data_Preprocessing.ipynb: Feature scaling, encoding, preparation and EDA & Data Visualization.

Mini_Project_4_Regression.ipynb: Model training, hyperparameter tuning, and evaluation.

Mini_Project_4_Clustering.ipynb: Unsupervised learning, market segmentation, and cluster analysis.

Mini_Project_4_Streamlit.ipynb: Code for the interactive deployment app.

📊 Dataset Features

The diamond models analyze 10 key features, including:

The 4Cs (Core Valuation Features):


Carat: Diamond weight. Influences price exponentially.

Cut: Cut quality (Fair to Ideal). Affects brilliance.

Color: Color grade (J to D). D is colorless/best.

Clarity: Flaw measurement (I1 to IF). IF is flawless.


Dimensional Attributes (Size in mm):


x: Physical length.

y: Physical width.

z: Physical depth.


Proportional Ratios (Light Reflection Metrics):


depth: Total depth percentage. Affects sparkle.

table: Top facet width percentage. Reflects light.
